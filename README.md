# FitLife #

## Цифровой фитнес-трекер. Программа для расчета основных показателей здоровья ##  
*Автор - Yulia Bulgakova*  

Программа (файл fit_life.py) позволяет весли учет основных показателе здоровья человека. Вот ее основные шаги:

1. Запустите прорамму на исполнение;
2. Программа попросит ввести Имя, возраст (в виде целого числа), вес и рост человека;
3. Введена дополнительная проверка корректности заполнения возраста:
 - Если возраст введен в виде строки или не введен, программа выдаст сообщение об ошибке и попросит повторно ввести возраст в виде целого числа. Или ввести слово стоп для остановки работы программы и выхода из опроса; 
 - Если возраст введен правильно программа продолжит работу и далее попросит ввести вес и рост человека;
4. Далее программа выполнит расчет показателей Индекс массы тела (ИМТ) и рекомендуемой нормы воды в день;
5. Итоговый расчет оформлен в виде отчета с краткой информацией о человеке: Имя, возраст, ИМТ, рекомендуемая норма воды в день.
